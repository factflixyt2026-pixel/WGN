WG WayGo · Návod

1. Supabase

Vytvor projekt na Supabase. V každom HTML súbore nahraď YOUR_PROJECT a YOUR_SUPABASE_ANON_KEY vlastnými hodnotami. Nikdy nevkladaj service_role key do HTML.

2. Databáza

Otvor database-setup.html, skopíruj SQL a spusti ho v Supabase SQL Editor.

3. Prihlasovanie

Zapni Email, Google a Apple v Supabase Authentication → Providers. OAuth potrebuje vlastné nastavenie u Google a Apple. Nastav povolené redirect URL na svoju doménu.

4. Spustenie

Hostuj stránky cez HTTPS. Na lokálne testovanie použi lokálny HTTP server; neotváraj cez file://.

5. Admin a VIP

Admin rolu nastav bezpečne cez Supabase Dashboard/Admin API v app_metadata: {"role":"admin"}. Nikdy nevystavuj service_role key. Znova sa prihlás a otvor admin.html.

6. Limity

Free účet má 20 študijných záznamov mesačne; VIP nemá tento limit. Kontrola je v databáze.

Poznámka

Obsahové HTML príspevkov sú zatiaľ vynechané. Pred produkciou otestuj OAuth, RLS, admin a limity.
